# links_for_read

Lista personal de enlaces pendientes de leer. No es código: cada carpeta agrupa un tema y contiene un archivo `.txt` con una URL por línea.

| Carpeta | Contenido |
| --- | --- |
| `agent_skills/` | Recursos sobre skills para agentes de IA y herramientas relacionadas |
| `assets/` | Referencias de diseño: guías de marca, estilos e inspiración de interfaces |
| `laravel/` | Artículos de Laravel News sobre novedades del framework |

Para agregar un enlace, añade la URL al archivo del tema correspondiente (o crea una carpeta nueva). Los enlaces pueden quedar desactualizados con el tiempo.
